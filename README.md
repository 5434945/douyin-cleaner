# 抖音清爽刷 v0.4.1

[下载 v0.4.1 安装包](https://github.com/5434945/douyin-cleaner/releases/download/v0.4.1/douyin-cleaner-v0.4.1.zip) · [更新记录](CHANGELOG.md) · [全部版本](https://github.com/5434945/douyin-cleaner/releases)

Chrome / Edge 浏览器插件。在 **抖音网页版的「推荐」视频流** 中，自动跳过有明确页面标识或接口广告标记的广告、推广和直播推荐。商品卡、购买入口可用单独开关过滤。

## 安装（约 1 分钟）

1. 将 `douyin-cleaner-v0.4.1.zip` 解压到一个长期保留的文件夹。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启页面上的「开发者模式」。
4. 点击「加载已解压的扩展程序」（部分 Edge 版本称「加载解压缩的扩展」）。
5. 选择 **直接包含 manifest.json 的解压文件夹**。不要选择 ZIP，也不要选它的上级目录。
6. 打开或刷新 https://www.douyin.com/ ，点击左侧「推荐」。
7. 在浏览器右上角扩展菜单中打开「抖音清爽刷」，可将它固定到工具栏。

加载后请保留整个文件夹：移动或删除它会导致插件失效。插件无需 npm、构建命令或服务器即可使用；`tests/` 仅供开发者验证。

## 默认行为

| 选项 | 默认 | 说明 |
|---|---|---|
| 自动过滤 | 开启 | 总开关；快捷键 Alt + Shift + S |
| 广告与推广 | 开启 | 广告专用节点、信息区明确标签，以及可关闭的图标兼容规则 |
| 直播推荐 | 开启 | 推荐流中的直播卡片或直播入口 |
| 带货视频 | 关闭 | 开启后也跳过已识别商品卡与购买入口的内容 |
| 跳过提示 | 开启 | 成功切换后提示原因，可返回并放行 |
| 广告图标兼容识别 | 开启 | 识别作者信息区中已有脚本使用的特定 SVG 特征，误判时可关闭 |
| 接口广告标识识别 | 开启 | 当前视频 ID 匹配且推荐接口明确标为广告时触发 |
| 跳过时遮挡广告并静音 | 开启 | 只在广告自动切换期间生效，可单独关闭 |
| 黑名单作者 | 开启 | 按主页 ID 自动跳过视频和直播推荐 |
| 自动收录明确推广作者 | 开启 | 品牌相关且有明确广告／合作披露时保存作者与依据 |
| 画面稳定等待 | 250 ms | 可调整为 200～1500 ms；标识稍后出现时仍会重检 |

点击「本条放行」，当前内容会在本次页面会话中放行 10 分钟。点击「返回并放行」，仅在仍停留于刚刚跳过内容的下一条时返回；浏览到其他内容后，请手动回看再使用「本条放行」。手动向上翻回刚跳过的内容也会将其临时放行。

「将当前作者加入白名单」按作者主页的稳定 ID 保存。白名单作者的广告、带货和直播均保留；可在「更多设置」移除。

输入框聚焦、有可识别弹窗/评论列表、标签页在后台时暂停。真实手动切换会取消正在进行的自动操作。统计在确认切换成功后增加，失败不计入成功数量。

## v0.3.0 作者黑名单与推广增量收录

- 预置 2 个有公开推广披露／积分激励记录的账号，依据详见 BLOCKLIST-SOURCES.md。仅升级时没有黑名单字段的设置会初始化首批名单；之后手动清空不会重新补回。
- 黑名单按作者主页稳定 ID 匹配，作者的所有可识别推荐视频和直播推荐都会跳过，不只跳过商业内容。不能读到作者 ID 时保留，不按昵称猜测。
- 「屏蔽当前作者」一键加入，并移除同作者的白名单；「加入白名单」会将该作者移出黑名单。白名单和本条临时放行优先。
- 「管理黑名单」可移除、合并导入 JSON／作者主页链接、导出名单、打开依据。移除的 ID 会记录为自动收录排除项；主动再次屏蔽或导入时解除排除。最多 1000 个作者和 1000 个排除项。
- 默认开启「自动收录明确推广作者」：当前推荐视频简介涉及华为／鸿蒙相关品牌，并且有明确广告标记或严格合作推广披露时收录；显式积分推荐推广也可作为依据。不使用普通品牌话题、作者观点、评论或图标兼容特征单独判定。
- 自动收录需读到稳定作者 ID、数字视频 ID 和当前 video 元素，通过白名单、放行、手动操作和画面稳定保护。只保存精简证据链接和规则，不后台搜索全站、不采集完整文案，也不修改抖音原生拉黑列表。
- 「黑名单作者」与「自动收录明确推广作者」可以分别关闭。关闭黑名单过滤也停止收录；黑名单成功跳过有独立统计。

这不是“所有 KOC 名单”，公开合作披露不证明长期签约或实际收款。首批有两种不同依据，见 BLOCKLIST-SOURCES.md。自动规则表示当前视频有品牌相关推广信号，不保证广告付款方就是华为；误收录时可移除或加入白名单。

## v0.2.0 广告增强

- 追加推荐接口广告标记识别：只观察 `/aweme/v1/web/tab/feed/` 中 `aweme_list` 的字符串 `aweme_id` 和布尔 `is_ads`。仅在当前视频 ID 完全匹配且 `is_ads === true` 时提供广告判断；不根据作者是否开播、广告数据对象的存在或文案猜测。
- 同时覆盖 fetch 和 XMLHttpRequest。原请求、响应和 fetch Promise 保留；不删除推荐条目、不修改响应、不阻断网络请求。关闭总开关、广告开关或接口识别开关后停止解析，清空缓存。已经执行的普通页面请求不会被取消。
- 开始自动跳过广告时短暂覆盖卡片并静音其 video 元素。切换、放行、暂停、手动操作、离开页面或失败时恢复原静音状态；另有 4.2 秒遮挡兜底清理。默认开启，可在更多设置关闭。
- 原有白名单、手动操作、弹窗、返回放行与稳定等待保护继续适用。直播沿用页面识别，不使用作者直播状态推断当前内容。

接口结构依据公开历史资料和独立模拟测试，尚未验证该账号当前真实广告响应。平台可能改字段、端点或不提供稳定视频 ID，届时此补充规则不生效，原有页面检测仍运行。页面 MAIN 环境可能受网站脚本干扰；桥接数据仅作为识别信号，不能调用扩展设置或其他特权操作。

## v0.1.2 直播漏检修复

- 普通视频节点还留在页面中时，独立的直播卡片也会参与当前内容检测。旧版只在完全没有普通视频节点时检查这类直播。
- 直播入口文字直接放在按钮或链接上时也能识别；原有规则只搜索部分文本标签。
- 保留直播卡片所在的完整滑动页范围，读取房间 ID 或房间链接，确认切换后才增加直播统计。
- 继续排除普通视频的作者直播头像、昵称、简介和评论。关闭直播开关、白名单、输入与弹窗暂停依旧有效。

这些漏检已用本地 Chrome 回归复现并修复。真实账号的不同直播页面结构仍需实测，见 TEST-REPORT.md。

## v0.1.1 速度调整（保留）

- 默认画面稳定等待由 450 ms 缩短为 250 ms；旧版保存的默认值会在读取时迁移，其他自定义数值保留。更新后仍可手动调回 450 ms。
- 手动方向键、鼠标滚轮和明确的上一条/下一条按钮操作后，暂停检测由 800 ms 缩短为 350 ms。连续操作会重新计时；其他点击和触摸仍保留 800 ms 保护。
- 页面变更检测延迟由 100 ms 缩短为 60 ms；切换确认由 180 ms 缩短为 120 ms，并移除确认后重复等待。
- 保留内容 ID、画面位置、可见范围和实时规则检查。输入/弹窗暂停、白名单、放行、失败重试上限保持有效。

已有安装：如果加载的是本次交付的原 `outputs/douyin-cleaner` 文件夹，文件已更新；在 Chrome 扩展管理页点击该插件的刷新按钮，再刷新抖音。若加载的是其他位置的解压目录，请先用新 ZIP 中的文件替换。更新需要重新加载扩展，只刷新抖音网页不会更新浏览器中已缓存的插件脚本。

## 范围与限制

- 面向电脑 Chrome / Edge，使用 Manifest V3，Chrome / Edge 111 或更新版本。手机抖音 App 不受此插件控制。
- 仅推荐视频流启用自动操作。搜索、视频详情、用户主页、关注页、主动进入的直播间不自动跳过。
- 当前版本基于页面与接口明确标识识别；没有标识的软广、视频画面或语音中的推广暂不识别。
- 兼容规则中的 SVG 图标特征可能随抖音改版变化，不等于平台稳定接口。误判时先关闭「广告图标兼容识别」。
- 点击下一条失败时尝试一次键盘兜底，然后停止。本条会保留，避免无限切换。
- 刚进入页面时可能短暂显示广告画面。这是页面检测后的自动跳过，不会阻止广告请求或保证完全无广告帧。
- 已验证本地模拟场景和当前网页版推荐流的主要节点。不同账号、登录状态、A/B 页面中的真实广告与直播仍需进一步实测。

## 常见问题

**面板一直提示等待推荐页面：**安装后先刷新抖音，再点击左侧「推荐」。首页宫格、搜索和详情页不属于支持范围。

**没有跳过某个广告：**确认「广告与推广」已开启。展开「诊断信息」查看当前规则；没有页面或接口明确标识的软广不会触发。若页面改版，可导出诊断用于适配。

**正常视频被跳过：**在提示中点击「返回并放行」。若命中图标兼容规则，关闭对应选项；若只想保留特定作者，加入白名单。带货开关开启后，普通挂商品的视频也会被跳过。

**更新插件：**替换文件夹中的源码，在扩展管理页点击该插件的刷新按钮，再刷新抖音。不要先卸载；卸载会删除本地设置。

**快捷键冲突：**在浏览器扩展快捷键页面调整 Alt + Shift + S。

## 隐私

插件仅声明 `storage` 权限，页面脚本仅匹配 `https://www.douyin.com/*` 和 `https://douyin.com/*`。不访问 Cookie、密码，不调用远程 API，不上传视频或浏览记录。

本机存储：开关、稳定等待时间、用户主动添加的白名单作者 ID/名称、用户屏蔽的作者 ID／昵称／精简证据链接、自动收录排除 ID、分类累计统计，以及最近 20 条「时间、类型、规则编号」。推荐接口的精简 ID/广告布尔值缓存最多 500 条；页面会话中的内容标识、接口缓存和放行记录只存于内存，刷新后清除。

导出的诊断包含设置开关、规则、累计数量和识别状态，不含视频地址、文案、作者 ID/名称。导出的作者名单包含用户主动管理的作者 ID／昵称及精简推广依据，和诊断导出分开。清空统计可删除计数和最近记录；卸载插件可清除全部插件存储。

## 源码结构

- `blocked-authors.js / BLOCKLIST-SOURCES.md`：首批公开依据名单和核查范围。
- `manifest.json`：匹配域名、权限、快捷键。
- `core.js`：页面选择器、识别规则、当前内容定位与 ID 读取。
- `feed-data.js / feed-capture.js`：推荐接口只读观察、字段校验、仅传递 ID 与广告布尔值。
- `content.js`：监听页面变化、手动操作、切换确认、失败控制、放行提示。
- `background.js`：串行写入统计，处理开关和白名单，避免多个标签页计数相互覆盖。
- `popup.html / popup.css / popup.js`：设置面板和诊断。
- `tests/`：无第三方依赖的核心测试与本地浏览器回归页面。

开发者验证：安装 Node.js 后，在此文件夹执行 `node --test tests/core.test.cjs tests/feed.test.cjs`；执行 `node tests/serve.mjs` 后打开 http://127.0.0.1:8765/tests/fixture.html ，点击「运行全部测试」。打开 http://127.0.0.1:8765/tests/speed.html ，点击「准备测量」后按向下方向键，可测量跳过响应。测试页模拟浏览器扩展消息和存储，执行交付的核心、内容、后台脚本；不能代替浏览器扩展真实安装和抖音各账号实测。

许可证见 `LICENSE`，公开参考来源见 `REFERENCES.md`，本版验证情况见 `TEST-REPORT.md`。

## v0.4.0 手动标记广告

1. 在推荐流停留于漏掉的广告，打开插件，点击“标记本条为广告”。
2. 插件记住该视频的稳定 ID；开启自动过滤和广告开关时，本条及以后再次遇到的同一视频会跳过。仍保留画面稳定等待、白名单、本条放行、输入暂停保护。
3. 误标可点击“取消本条广告标记”，或展开“我标记的广告”移除对应条目。移除只取消人工标记；若该视频仍具有平台广告标识，自动规则仍可能跳过，可用“本条放行”。

最多保存 2000 条。只在本机 chrome.storage.local 保存你主动标记的视频 ID 和最多 100 字的简介，便于撤销；不上传、不分享，也不修改抖音账号。不是模型训练；不同 ID 的重发、剪辑和相似广告不会因此被屏蔽。没有稳定视频 ID 时禁用／拒绝标记，面板对应的视频已经切换时提示重新确认，避免误标。

旧版设置与已有名单继续保留。清空统计不会清空广告标记。安装后在 Chrome 扩展管理页重新加载，并刷新抖音，确认 v0.4.0。
