# v0.4.5 — 新增快速拉黑快捷键 Alt + Shift + B

## 更新内容

- 在推荐视频上按 Alt + Shift + B，将当前作者加入插件黑名单；过滤开启时按现有规则跳过，暂停时仅保存。
- 面板显示快捷键；支持移除名单撤销。输入、弹窗、后台标签页和非推荐页面受到保护。
- 后台转发快捷键消息不进入存储队列，避免页面回调保存造成死锁；无新增权限。

## 验证

Node 30 项、Chrome 本地回归 92 项通过；验证快捷键消息转发、保存和暂停保护。实际 Chrome 快捷键注册需安装后确认，冲突时可在 chrome://extensions/shortcuts 修改。

测试以本地模拟推荐流、扩展消息及存储为主，不能视为所有抖音账号、页面样式和真实广告的端到端保证。详情见该标签下的 TEST-REPORT.md。

## 安装与更新

下载附件 `douyin-cleaner-v0.4.5.zip`，解压后选择直接包含 `manifest.json` 的文件夹，在 Chrome 开发者模式中加载。
该安装包的 manifest.json 位于 ZIP 根目录。
更新时保持原扩展目录及扩展 ID，覆盖文件后重新加载扩展并刷新抖音，以保留本地设置和名单。

推荐使用本版本。

仅作用于抖音网页版推荐流，所有设置保存在本机；作者屏蔽是插件跳过，不调用抖音原生拉黑。
