# v0.1.0 — 首版：广告、直播推荐与可选带货过滤

## 更新内容

- 在推荐流中识别广告、推广、直播推荐；带货过滤使用独立开关。
- 提供本条放行、返回并放行、作者白名单、统计及输入／弹窗时暂停。

## 验证

Node 8 项、本地浏览器模拟推荐流 35 项通过。

测试以本地模拟推荐流、扩展消息及存储为主，不能视为所有抖音账号、页面样式和真实广告的端到端保证。详情见该标签下的 TEST-REPORT.md。

## 安装与更新

下载附件 `douyin-cleaner-v0.1.0.zip`，解压后选择直接包含 `manifest.json` 的文件夹，在 Chrome 开发者模式中加载。
本历史安装包含一层 douyin-cleaner 文件夹，请选择这一层，避免“清单文件缺失”错误。
更新时保持原扩展目录及扩展 ID，覆盖文件后重新加载扩展并刷新抖音，以保留本地设置和名单。

历史版本归档；建议使用 [最新版本](https://github.com/5434945/douyin-cleaner/releases/latest)。

仅作用于抖音网页版推荐流，所有设置保存在本机；作者屏蔽是插件跳过，不调用抖音原生拉黑。
