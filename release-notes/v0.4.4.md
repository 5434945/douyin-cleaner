# v0.4.4 — 修复播放器购物入口漏识别

## 更新内容

- 补充 xgplayer-shop-anchor 购物入口，覆盖没有商品 data-e2e 属性或 href 的购物锚点。
- 只检查当前卡片中的可见购物入口，排除评论、昵称、隐藏节点；保留用户带货开关设置。

## 验证

Node 28 项、Chrome 本地回归 89 项通过；使用实站读取到的购物入口结构构建回归，未确认已安装扩展更新后的同一视频切换。

测试以本地模拟推荐流、扩展消息及存储为主，不能视为所有抖音账号、页面样式和真实广告的端到端保证。详情见该标签下的 TEST-REPORT.md。

## 安装与更新

下载附件 `douyin-cleaner-v0.4.4.zip`，解压后选择直接包含 `manifest.json` 的文件夹，在 Chrome 开发者模式中加载。
该安装包的 manifest.json 位于 ZIP 根目录。
更新时保持原扩展目录及扩展 ID，覆盖文件后重新加载扩展并刷新抖音，以保留本地设置和名单。

历史版本归档；建议使用 [最新版本](https://github.com/5434945/douyin-cleaner/releases/latest)。

仅作用于抖音网页版推荐流，所有设置保存在本机；作者屏蔽是插件跳过，不调用抖音原生拉黑。
