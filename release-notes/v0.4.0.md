# v0.4.0 — 手动标记本条视频为广告

## 更新内容

- 新增手动广告标记、取消标记和名单管理；保存稳定视频 ID，下次遇到同一 ID 时跳过。
- 标记前校验弹窗所指的视频 ID，防止切换后误标；最多保存 2000 条。
- 本地规则学习不使用 AI 训练，不推断同作者的其他视频或重新上传的新视频 ID。

## 验证

Node 24 项、Chrome 本地回归 81 项通过；面板标记和移除已验证。

测试以本地模拟推荐流、扩展消息及存储为主，不能视为所有抖音账号、页面样式和真实广告的端到端保证。详情见该标签下的 TEST-REPORT.md。

## 安装与更新

下载附件 `douyin-cleaner-v0.4.0.zip`，解压后选择直接包含 `manifest.json` 的文件夹，在 Chrome 开发者模式中加载。
该安装包的 manifest.json 位于 ZIP 根目录。
更新时保持原扩展目录及扩展 ID，覆盖文件后重新加载扩展并刷新抖音，以保留本地设置和名单。

历史版本归档；建议使用 [最新版本](https://github.com/5434945/douyin-cleaner/releases/latest)。

仅作用于抖音网页版推荐流，所有设置保存在本机；作者屏蔽是插件跳过，不调用抖音原生拉黑。
