# v0.2.0 — 增加接口广告信号与广告遮挡

## 更新内容

- 可选地旁路观察推荐接口响应，以稳定视频 ID 和明确 is_ads 信号辅助页面识别。
- 加入已知 SVG 广告标识兼容及跳过时遮挡；接口观察不修改请求或响应。
- 此版本的遮挡逻辑会短暂修改静音状态；该行为已在 v0.4.3 移除，请使用最新版本。

## 验证

Node 14 项、Chrome 本地回归 54 项通过。

测试以本地模拟推荐流、扩展消息及存储为主，不能视为所有抖音账号、页面样式和真实广告的端到端保证。详情见该标签下的 TEST-REPORT.md。

## 安装与更新

下载附件 `douyin-cleaner-v0.2.0.zip`，解压后选择直接包含 `manifest.json` 的文件夹，在 Chrome 开发者模式中加载。
该安装包的 manifest.json 位于 ZIP 根目录。
更新时保持原扩展目录及扩展 ID，覆盖文件后重新加载扩展并刷新抖音，以保留本地设置和名单。

历史版本归档；建议使用 [最新版本](https://github.com/5434945/douyin-cleaner/releases/latest)。

仅作用于抖音网页版推荐流，所有设置保存在本机；作者屏蔽是插件跳过，不调用抖音原生拉黑。
