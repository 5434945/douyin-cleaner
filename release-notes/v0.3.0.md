# v0.3.0 — 作者黑名单及有依据的推广账号收集

## 更新内容

- 支持按稳定作者 ID 拉黑、导入、移除；白名单优先，名单保存在本机。
- 浏览时可收集具有明确商业推广依据的华为／鸿蒙智行相关作者，附来源；提供少量有公开依据的种子账号。
- 名单并非所有 KOC 的完整名单，也不据此断言账号存在付费关系；插件跳过不等同于抖音原生拉黑。

## 验证

Node 21 项、Chrome 本地回归 66 项通过；面板名单导入和移除已验证。

测试以本地模拟推荐流、扩展消息及存储为主，不能视为所有抖音账号、页面样式和真实广告的端到端保证。详情见该标签下的 TEST-REPORT.md。

## 安装与更新

下载附件 `douyin-cleaner-v0.3.0.zip`，解压后选择直接包含 `manifest.json` 的文件夹，在 Chrome 开发者模式中加载。
该安装包的 manifest.json 位于 ZIP 根目录。
更新时保持原扩展目录及扩展 ID，覆盖文件后重新加载扩展并刷新抖音，以保留本地设置和名单。

历史版本归档；建议使用 [最新版本](https://github.com/5434945/douyin-cleaner/releases/latest)。

仅作用于抖音网页版推荐流，所有设置保存在本机；作者屏蔽是插件跳过，不调用抖音原生拉黑。
